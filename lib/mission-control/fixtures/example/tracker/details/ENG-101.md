Key:      ENG-101
Type:     Story
Status:   Ready for Dev
Summary:  Add rate limiting to the export endpoint

Description
-----------
Exports are unbounded today; one tenant can saturate the worker pool.
Add a per-tenant token bucket in front of the export job enqueue.

Acceptance criteria
-------------------
- Given a tenant over its limit, then the export request returns 429.
- Given a tenant under its limit, then the export enqueues as before.
